## Before changing anything

- [ ] Capture the initial score/report.
- [ ] Run the read-only audit commands.
- [ ] Compare local accounts with the authorized list.
- [ ] Record installed applications and their paths.
- [ ] Record services and firewall profiles.
- [ ] Record current password and audit policies.
- [ ] Identify settings that could disrupt required functionality.

## Decision rule

For every proposed change, record:
1. The scenario requirement or policy it addresses.
2. The current observed value.
3. The desired value.
4. The exact command or UI action.
5. The verification command and result.
6. Score change, if any.

Do not treat a generic CIS recommendation as a scenario-specific scoring requirement without checking the image's instructions.
